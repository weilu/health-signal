# health-signal — Stage 2 (PR #4): Authentication (library-backed) + per-page access policy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gate the app behind a pluggable, **library-backed** `AuthProvider` — a DB-free `LocalAccountsProvider` using **fastapi-login** (session token/cookie) + **argon2** (hashing) with accounts from config/secrets — plus a config-driven **per-page access policy** (default locked, opt-in public). No hand-rolled session or cookie crypto. SSO (`OIDCProvider` via Authlib) is a later stage that drops into the same seam.

**Architecture:** The provider **owns its login routes** (`install(app)`) and exposes `current_user(request)`. `create_app(config, auth_provider=None)` calls `provider.install(app)`, then applies the shared, provider-agnostic pieces: a `require_auth` dependency and an **access policy** (public paths bypass auth). `LocalAccountsProvider` wraps fastapi-login's `LoginManager` (token signing, cookie, `user_loader`) and verifies passwords with argon2 — we write only thin glue.

**Tech Stack:** FastAPI, Pydantic v2, **fastapi-login** (LoginManager), **argon2-cffi** (hashing), python-multipart (form login); Starlette `TestClient`. (Authlib is for the deferred OIDC stage, not this PR.)

**Spec:** `docs/specs/2026-09-23-reusable-surveillance-dashboard-design.md` (§3 gating, §7.2 AuthProvider, §7.4 access policy, §8 routes).

## Global Constraints

- Python ≥3.11; `src/health_signal/` layout; hatchling; **uv** dev/CI; wheel bundles `_ui/**`.
- **No hand-rolled auth crypto:** session token/cookie via **fastapi-login**; hashing via **argon2**. We must not write our own signer or cookie logic.
- **Cookie security:** the session cookie must be **HttpOnly + Secure + SameSite=Lax** (configure fastapi-login's cookie attributes; if its `set_cookie` doesn't expose all three, set them explicitly on the response — verify against the installed fastapi-login version).
- **DB-free:** accounts from `HEALTH_SIGNAL_ACCOUNTS` (JSON email→argon2-hash) + `HEALTH_SIGNAL_SECRET_KEY`; `from_env` fails fast without the secret. No database, no registration.
- **Outside-in tests first** (TestClient via `https://testserver` so Secure cookies replay), unit for focused logic. Public repo, **synthetic accounts/secrets only** (throwaway emails, locally-hashed throwaway passwords, literal test secrets).
- **`/healthz`, the provider's login routes are always public.** `/api/me` requires auth. The SPA catch-all + `/api` gate consult the access policy; a **public** path bypasses auth, everything else is locked (default).
- **Delivery:** one PR (≤800 LOC); Copilot → user review → merge; CI + compliance green; author `Wei Lu <luwei.here@gmail.com>`.

### Task 1: `LocalAccountsProvider` via fastapi-login + argon2

**Files:** Modify `pyproject.toml`; Create `src/health_signal/auth.py`; Test `tests/test_auth.py` (unit).

**Interfaces produced:**
- `class User(BaseModel)`: `email: str`.
- `class AuthProvider(Protocol)`: `install(self, app: FastAPI) -> None`; `current_user(self, request: Request) -> User | None`.
- `class LocalAccountsProvider`: `__init__(self, accounts: dict[str,str], secret_key: str, max_age_s: int = 43200)`. Internally builds a fastapi-login `LoginManager(secret_key, token_url="/login", use_cookie=True, cookie_name="hs_session")` with `default_expiry=timedelta(seconds=max_age_s)`, registers a `@manager.user_loader()` that returns `User(email=sub)` iff `sub in accounts`, and configures the cookie as HttpOnly+Secure+SameSite=Lax. Methods: `authenticate(email, password) -> User | None` (argon2 verify, dummy-hash on unknown email to equalize timing, catch `(VerifyMismatchError, InvalidHashError)`); `install(app)`; `current_user(request)` (use the manager to read+validate the cookie token, returning None when absent/invalid rather than raising).
- `def hash_password(password: str) -> str`; `def from_env(max_age_s=43200) -> LocalAccountsProvider` (reads env; raises `RuntimeError` without `HEALTH_SIGNAL_SECRET_KEY`).
